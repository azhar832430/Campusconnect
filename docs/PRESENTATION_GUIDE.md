# Presentation / video guide (suggested 5–7 minutes)

1. **Introduction (0:00–0:40):** State the problem, domain, objectives, and technology stack.
2. **Interface and responsiveness (0:40–1:20):** Show dashboard, navigation, and a narrow/mobile layout.
3. **Student CRUD (1:20–2:10):** Create, read/search, update, and delete a test student.
4. **Course CRUD (2:10–3:00):** Create, read/search, update, and delete a test course.
5. **Enrollment CRUD (3:00–4:10):** Create a linked enrollment, view it, change its status, and delete it.
6. **Validation and relationships (4:10–5:00):** Show an invalid form, duplicate handling, delete confirmation, and why a linked student/course cannot be deleted.
7. **Persistence and architecture (5:00–5:50):** Refresh after saving a record, show API health, explain React → Express → MongoDB.
8. **Wrap-up (5:50–6:10):** Mention actual testing, limitations, and live URL.

Use test data only. Do not show passwords, database credentials, or private student information. Upload to Google Drive and verify the instructor can view the recording.
